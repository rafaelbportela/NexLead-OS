# NexLead OS — Protótipo interativo do aplicativo do cliente

Abra `index.html` no navegador. Não é necessário instalar dependências.

## Funcionalidades
- Entrada demonstrativa (qualquer e-mail e senha com 4+ caracteres; não usar credenciais reais)
- Dashboard e métricas fictícias
- Solicitação de 20 a 1.000 leads, três temperaturas, créditos e análise de viabilidade ilustrativa
- Lista de leads com detalhes
- Kanban com drag-and-drop e mudança de etapa
- Campanhas e acompanhamento fictícios
- Assistente com respostas locais pré-programadas (não é IA real)
- Relatórios, planos e edição do perfil comercial
- Persistência local no navegador via localStorage

## Limitações
Sem backend, autenticação segura, pagamentos, prospecção, enriquecimento, e-mails, leads reais ou IA conectada. Dados e preços são fictícios. Nenhuma promessa comercial está implementada. O logo original da NexLead está incluído em `assets/logo-original.jpg` para uso futuro; o aplicativo usa um monograma simplificado para a marca na navegação.

## Próximos passos para produção
Autenticação real, isolamento de dados por organização, pagamentos, motor de prospecção, integração com provedores, critérios de validação e LGPD.
